## 这份词表解决什么问题

项目视觉方向接受为漫剧 / 二维漫画形态后，写关键帧 `generic_prompt` 的人会撞上同一个
问题：身份、地理、边界事实都绑好了，但"这一帧要什么画风、什么光影、防什么画面风险"
每次都要重新发明措辞，同一个项目里不同集的提示词各说各话。这份词表把漫剧形态下常用的
风格词与质量词按镜头类型整理成可选项，让同一项目的用词稳定、可复用。

它是 [keyframe-craft.md](keyframe-craft.md) 的补充，不是替代：十二项事实与"写完之后过一遍
可渲染检查"照旧逐条写满，本词表只负责其中"风格 / 光影 / 画质"那一小段的选词。
事实先于审美词的优先级不变——词表里的任何词都不能顶替身份、地理、构图与连续性事实。

## 规则分级与语言政策

- 本词表全部是 `taste_option`：它是供挑选的词汇，不是质量门槛。某个词被创作者写进
  `creator_authority/visual_direction` 并接受之后，它才从可选项变成必须投影的形态约束；
  在那之前，审查不得只因"没用词表里的词"判为问题。
- 不用量、词数或"必须包含某词"设门槛。风格词每类取一两个、彼此不打架即可；质量词只写
  当前帧真实存在的风险。
- 提示词正文语言跟随 `short-drama.json#/format/prompt_language`（独立运行时由用户指定，
  未指定为 `en`）。本词表给中文词根，写入 prompt 时译为项目声明的语言；改了描述语言不等于
  改了画面里的可读文字，可读文字仍由已接受的文字政策决定。
- 正文里不写镜头 / 记录 ID、规则编号与状态词（`SHT-21`）；下表的"镜头类型"只是选词入口，
  不进提示词正文。

## 三层词根结构

每条漫剧关键帧提示词按三层组织，顺序不可颠倒：

1. **场景 / 主体词**：这一帧拍谁、在哪、做什么——来自已接受的资产、镜头边界与
   [keyframe-craft.md](keyframe-craft.md) 的十二项，**本词表不提供这一层**，也不允许用风格词
   冒充它。
2. **风格词**：画风基底 + 光影色调 + 镜头感，从已接受视觉方向选取，决定"这一帧用什么
   漫剧语言被看见"。
3. **质量 / 格式词**：分辨率、构图要求、与剧本 / 视觉方向的一致性声明，以及只针对当前帧
   真实风险的排除项。

## 镜头类型一：叙事关键帧

用于承担剧情转向、揭示或场尾落点的关键画面，是漫剧分镜的默认帧型。

| 分组 | 词根（按项目视觉方向挑选，不堆叠） |
|---|---|
| 画风基底 | 赛璐璐动画帧、厚涂漫画、平涂漫感、国风条漫质感、日系漫剧画风、复古胶片漫感、极简叙事画风 |
| 镜头感 | 漫画分镜感、电影运镜感、强透视、特写叙事、动态张力 |
| 光影与色调 | 暗调叙事、朦胧电影柔光、冷色调压抑、暖调治愈、氛围感光影、高冲突戏剧感、魔幻渲染 |
| 画质与画面 | 4K、画面干净、无多余元素 |
| 构图与叙事 | 分镜构图、镜头语言明确、叙事画面、画面构图紧凑 |
| 与上游一致 | 人物动作完整、色彩贴合剧本与已接受视觉方向、光影方向全场统一 |

## 镜头类型二：对话镜头（中近景）

用于以台词和神态为主的镜头。漫剧剪辑中这类镜头占比最高，风险集中在面部与背景的干净程度。

| 分组 | 词根 |
|---|---|
| 画风基底 | 日系二次元、国风漫剧、平涂漫画、厚涂写实、复古港漫、韩式漫画、水彩叙事、简约漫感 |
| 光影与情绪 | 柔和侧光、戏剧打光、低饱和叙事、胶片颗粒、清冷氛围感、热血张力、忧伤氛围感、甜系柔和、暗黑压抑 |
| 构图特征 | 漫画对话框留白、人物半身构图、情绪神态突出 |
| 画质与画面 | 4K、中近景、面部神态清晰、画面干净、色彩统一 |
| 剪辑适配 | 构图聚焦人物、适合漫剧剪辑、光影贴合情绪、无杂乱背景、镜头裁切适配 |

"漫画对话框留白"只在交付工作流真的要在画面上叠字幕 / 对话框时使用；它是构图决定，
不是每镜默认。

## 镜头类型三：动作 / 特效帧

用于打斗、施法、爆发瞬间。注意：这些词描述的是**这一帧里冻结住的可见处理**
（拖影、粒子、光刃凝固在画面里），不是动作过程——"先、再、最后"与运镜过程仍属于
`$short-drama-video-prompts`，不写进冻结帧。

| 分组 | 词根 |
|---|---|
| 动态表现 | 高速动态模糊、张力透视、流光拖尾、漫感爆炸、大动态构图 |
| 特效体系（按题材选一系，不混用） | 仙侠剑气 / 水墨国风打斗；赛博能量光束 / 霓虹光刃；魔幻魔法光效 / 冰系冰晶特效；火焰硝烟 / 金属火花 / 电光雷暴 / 沙尘飞扬 |
| 质感层次 | 破碎粒子效果、破碎碎片、暗黑黑雾、硝烟弥漫 |
| 画风基底 | 热血二次元、厚涂漫画、国风条漫质感 |
| 画质与画面 | 8K、动态模糊、动作张力强、冲击力画面、强对比光影 |
| 与上游一致 | 特效层次丰富、特效通透、运动轨迹清晰、无肢体畸变 |

## 同一个结构在资产参考图上的用法

三层词根不只服务分镜关键帧。`$short-drama-image-prompts` 的角色立绘与场景板提示词可以
复用同一结构，选词入口换成资产类型：

- **角色立绘**：风格词如 日系赛璐璐、厚涂写实、国风仙侠、复古港漫、Q 版萌系、水彩质感；
  质量词如 全身立绘、纯色背景、角色完整、边缘干净、人物比例正确、高对比度。
- **世界观场景板**：风格词如 宏大仙侠仙境、赛博朋克都市、古风古城全景、末世废土荒原、
  日式和风古街；质量词如 超宽全景、宏大透视、电影级构图、环境细节丰富、大气氛围感。

资产参考图的权威写法仍在 `$short-drama-image-prompts` 的
[通用配方与视觉锚点](../../short-drama-image-prompts/references/common-recipe.md)；这里只
说明选词结构是同一个，避免两边各造一套词汇。

## 组合方法：选镜头类型，填主体

1. 先按 [keyframe-craft.md](keyframe-craft.md) 写完十二项事实：谁、在哪、边界瞬间的姿态 /
   目光 / 持物、构图、机位、光线、排除项。这一步不碰本词表。
2. 判断这一帧的类型：叙事关键帧 / 对话镜头 / 动作特效帧。类型由镜头目的决定，不由
   "想要好看的特效"决定。
3. 从已接受视觉方向取风格词：画风基底一个 + 光影色调一两个；题材外的体系不混用。
4. 质量词只写当前帧的真实风险：对话镜头写"面部神态清晰、无杂乱背景"，动作帧写
   "无肢体畸变、运动轨迹清晰"；没有的险不防。
5. 按"事实 → 风格 → 质量"的顺序接在十二项之后，译为项目声明的提示词语言。

## 完整示例（合成改写）

竖屏 9:16 漫剧，已接受视觉方向为"国风条漫质感 + 暗调叙事"。场：雨夜天台对峙，叙事
关键帧。十二项事实按 keyframe-craft 写满后，风格与质量段是这样接上的：

```text
竖屏 9:16 中近景。机位在轴线左侧、平视略低约五度，标准焦段。前景是湿透的栏杆扶手
（占下缘约六分之一）；中景两人对峙；背景虚焦的城市灯斑与雨幕。三分构图，她落右三分线。
她：栏杆内侧，双手握栏杆，身体朝向正前，视线落在对方胸口，无持物。人物乙：站她正前方
约两步、略偏画面左，一手插袋，身体朝向她。光自画面右上高杆灯斜下为主光（硬），左侧
留暗。视觉重点在她握栏杆的双手。位置与持物与上一镜相同。
风格：国风条漫质感，暗调叙事，氛围感光影。
质量：4K，分镜构图，画面干净，色彩贴合剧本与已接受视觉方向，无多余元素。
排除：无动作过程，无雨丝拖影。
```

风格段的三个词全部来自已接受视觉方向；质量段只防这一帧真实的风险（雨夜 + 暗调容易
糊成一团，所以写"画面干净"；没有其他臆造风险）。删掉"风格 / 质量"两行，画面事实仍然
完整——这正是它们该处的位置。

## 反模式

1. **风格词打架**：同一帧并写"赛璐璐动画帧"和"厚涂写实"、"暖调治愈"和"冷色调压抑"。
   每类取一个，冲突的先回到视觉方向做选择。
2. **特效体系混用**：仙侠剑气与赛博能量光束同框。题材外的词再好看也不进本项目。
3. **质量词冒充事实**：用"8K、电影级"顶替"谁在谁正前方约两步"。词表在事实之后，
   不在事实之位。
4. **万能排除清单**：每帧都带一长串防畸变禁词。排除项只防当前帧的真实风险，
   否则正文被补丁稀释（与
   [production-shot-grammar.md](production-shot-grammar.md) 的反模式同源）。
5. **把镜头类型写进正文**："叙事关键帧、对话镜头"是选词入口，不是画面内容；
   正文不写分类名、编号与状态词（`SHT-21`）。
6. **词表当质量门槛**：审查时只因"没用词表词汇"打回。词汇被创作者接受进视觉方向之前，
   它只是 `taste_option`。
