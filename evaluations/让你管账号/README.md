（147,010 字节 / 52,552 字 / 20 章；版权与使用限制见 [NOTICE.md](NOTICE.md)）。

`reference-run/` 是这套技能对它的一次完整实跑，从原著一路走到 EP001 的视频提示词。

## 它专门覆盖 golden-project 没有的东西

这是它存在的理由，不是附带的好处：

- **`[VO]` / `[OS]`**：本集 18 句口播里 8 句是画外音。`golden-project` 八集里这两个标签出现 0 次。
  两个缺陷曾因此活着——时长估算计零秒、配音本装不下它们。
- **完整配音本**：18 句全部进表。`golden-project` 没有配音本。
- **被改稿过的剧本**：索引带真实的修订历史，可以验证块号按内容保留、被改写的块退役。
- **真实长度的原著**：20 章的索引与 span，不是手写的几行样例。
